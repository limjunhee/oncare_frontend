- 요양보호사 공개 구인공고
- 보호자의 요양보호사 검색
- 보호자가 요양보호사를 선택하는 화면
- 요양보호사 구직 지원
- 결제
- 리뷰 중심의 매칭 플랫폼
- 커뮤니티
- 쇼핑몰

핵심 기능은 반드시 다음에 집중해주세요.

1. 이용자 방문 일정 관리
2. 요양보호사 근무 가능시간 관리
3. 조건 기반 자동편성
4. 기존 담당관계를 고려한 돌봄 연속성
5. 업무 편중 진단
6. 일정 충돌 진단
